# Tech Company SQL Database Project

## Project Overview

A MySQL relational database project for managing employees across four departments: Development, Testing, Production, and DevOps.

## Technologies Used

- MySQL
- SQL
- Git
- GitHub

## Database Features

- Database and table creation
- Primary keys and auto-increment IDs
- Unique employee and department email addresses
- Foreign key relationships
- Sample employee data
- SELECT queries and filtering
- INNER JOIN and LEFT JOIN
- GROUP BY and COUNT

## Project Structure

- `sql/01_create_database.sql` — Creates the database
- `sql/02_create_tables.sql` — Creates the tables and relationships
- `sql/03_insert_sample_data.sql` — Inserts sample data
- `sql/04_queries.sql` — Contains practice and reporting queries

## How to Run

1. Install MySQL Server and open MySQL Workbench.
2. Execute the SQL files in numerical order.
3. Run the queries in `04_queries.sql`.
4. Review the department-wise employee results.

## Learning Objectives

This project demonstrates relational database design, SQL constraints, data insertion, filtering, joins, and aggregate functions.

## Note

All employee information in this project is fictional sample data.
